# 🤖 Discord 多功能社群機器人

這是一個基於 `discord.py` 開發的強大多功能 Discord 機器人，整合了 AI 聊天、經濟系統、虛擬股市、音樂播放、多種賭場遊戲、自動廣播以及各種實用的伺服器管理工具。

## ✨ 功能特色

### 🤖 AI 聊天助理 (`ai_chat.py`)
- 整合 **Google Gemini 2.5 Flash** 模型，支援聯網搜尋最新資訊。
- 擁有獨立上下文記憶，自然親切的聊天體驗。
- 自動統計 Token 消耗，並具備記憶體管理與清除功能。

### 💸 經濟與虛擬股市 (`economy.py`, `finance.py`)
- **基礎經濟**：每日簽到、打工賺錢、轉帳系統。
- **虛擬股市**：內建 15 支特色虛擬股票（如：護國神山台積電、滷肉飯指數），價格每小時動態波動。
- **股市進階功能**：支援低買高賣、查看投資組合損益、購買內線消息與市場新聞自動推播。

### 🎰 娛樂與賭場遊戲 (`gamble.py`, `fun.py`, `game_panel.py`)
- **皇家 21 點**：支援多達 5 人同樂的完整 21 點撲克牌桌（支援雙倍下注、爆牌、黑傑克結算）。
- **賭場小遊戲**：拉霸老虎機、猜硬幣、骰子對決。
- **抽獎與活動**：全服金幣大放送抽獎系統、遊戲隨機抽籤面板。

### 🎵 音樂播放器 (`music.py`)
- 支援透過關鍵字或 YouTube 網址點播音樂。
- 內建 UI 控制面板（播放/暫停、下一首、停止、查看待播清單）。

### 🛠️ 實用工具與推播 (`link_fixer.py`, `broadcast.py`, `auto_voice.py`, `weather.py`, `food.py`)
- **連結自動修復**：自動將 Twitter/X, Instagram, TikTok, Threads 等社群連結轉換為可預覽的網址，並以 Webhook 偽裝原使用者發送。
- **自動動態語音**：點擊特定語音頻道自動創建專屬包廂，全空時自動銷毀。
- **每日推播**：早上 8 點自動推播 Google 台灣熱門新聞。
- **限免遊戲監控**：自動偵測並推播 Epic Games, Steam 等平台的限時免費遊戲。
- **生活助手**：即時天氣查詢、食物與手搖飲推薦（早午晚餐/宵夜）。

### 🏆 等級與個人檔案 (`leveling.py`, `profile.py`)
- 聊天賺取經驗值與升級通知（內建防洗頻冷卻）。
- 伺服器活躍排行榜。
- 整合個人檔案卡片，展示財富餘額、等級與收集到的隱藏成就稱號（如：夜貓子、賭神、股票大亨）。

### 🛡️ 伺服器管理 (`admin.py`, `logger.py`, `auto_reply.py`, `bug_report.py`)
- **日誌系統**：記錄訊息刪除/編輯、成員進出（含邀請者追蹤）、語音動態、頻道變更與指令使用。
- **自訂自動回覆**：管理員可自訂伺服器專屬的關鍵字回覆。
- **問題回報系統**：提供 UI 面板讓使用者一鍵開立回報單 (Ticket)，處理完畢自動備份文字檔發送給管理員。
- **一鍵清理**：管理員批量清除訊息。

## 🚀 環境需求

- Python 3.8+
- `discord.py`
- `google-genai` (Gemini API)
- `yt-dlp` & `PyNaCl` (用於音樂與語音)
- `FFmpeg` (音樂播放必備環境組件)
- `aiosqlite` / `aiohttp` / `Pillow`

## ⚙️ 安裝與執行

1. **複製原始碼到本地端**
   ```bash
   git clone <你的 GitHub Repo 網址>
   cd <專案資料夾>
   ```

2. **安裝 Python 依賴套件**
   ```bash
   pip install -r requirements.txt
   ```

3. **設定環境變數**
   在根目錄下建立一個 `.env` 檔案，並填入以下資訊：
   ```env
   DISCORD_TOKEN=你的_DISCORD_BOT_TOKEN
   GEMINI_API_KEY=你的_GOOGLE_GEMINI_API_KEY
   ```

4. **啟動機器人**
   ```bash
   python main.py
   ```
   *(註：主程式名稱請根據你實際的進入點檔案命名修改)*

## 📝 資料庫與儲存
本機器人使用輕量級的 `SQLite` (`bot_database.db`) 進行資料持久化，無需額外架設資料庫伺服器，啟動後會自動生成所需資料表。

## 💡 指令總覽
機器人支援 Discord 的斜線指令 (Slash Commands) 與前綴指令。
在頻道中輸入 `/help` 即可叫出內建的互動式指令清單與詳細分類說明！
