# Discord 社群多功能機器人 (Discord Community Bot)

本專案為基於 `discord.py` 開發的 Discord 多功能機器人。系統整合了 AI 對話助理、虛擬經濟與股市系統、音樂播放、多項互動遊戲、自動廣播推播，以及多種伺服器管理與實用工具，旨在提供更豐富的社群互動體驗與高效的伺服器管理方案。

## 🌟 核心功能特色

### 🤖 AI 對話助理 (`ai_chat.py`)
- 整合 **Google Gemini 2.5 Flash** 模型，支援即時聯網搜尋與多重聊天人格切換（如傲嬌、毒舌、貓娘等）。
- 具備獨立上下文記憶功能，提供自然流暢的對話體驗。
- 內建 Token 使用量統計 (`/quota`) 及記憶體資源管理機制。

### 💹 經濟與虛擬股市系統 (`economy.py`, `finance.py`)
- **基礎經濟**：提供每日簽到、虛擬工作任務與使用者間轉帳功能。
- **虛擬股市**：內建多款特色虛擬股票，價格隨時間與演算法動態波動。
- **進階金融功能**：支援股票買賣、投資組合未實現損益追蹤、內線消息訂閱、市場動態新聞自動推播，以及 `/stock_history` 即時歷史折線圖與大盤狀態分析。

###  娛樂與互動遊戲 (`gamble.py`, `fun.py`, `game_panel.py`)
- **多人卡牌遊戲**：支援至多 5 人連線之 21 點撲克牌系統，具備雙倍下注、爆牌及黑傑克等完整規則與結算機制。
- **互動小遊戲**：內建拉霸機、硬幣猜測與骰子對決等趣味功能。
- **社群活動**：支援伺服器抽獎系統與隨機遊戲抽籤 UI 面板。

### 🔞 老司機專區 (`nsfw.py`)
- **熱門爬蟲推播**：內建龐大片單庫，支援 `/av` 抽籤並動態爬取 Jable、MissAV、Hanime 等 4 大平台即時熱門榜單。
- **專屬車庫管理**：群友專屬的車牌推薦與管理系統 (`/my_av`, `/edit_av`, `/del_av`) 與排行榜點讚機制。
- **深夜福利**：每日深夜指定頻道自動發車推播。

### 🎵 音樂播放系統 (`music.py`)
- 支援透過關鍵字或 YouTube 連結點播音訊。
- 內建互動式 UI 控制面板，提供播放、暫停、切換曲目及待播清單查詢功能。

### 🛠️ 實用工具與自動推播 (`link_fixer.py`, `broadcast.py`, `auto_voice.py`, `weather.py`, `food.py`)
- **社群連結預覽修復**：自動解析 Twitter/X, Instagram, TikTok, Threads 等社群平台連結，並轉換為可預覽之網址，透過 Webhook 保持原發送者外觀。
- **動態語音頻道**：使用者進入特定頻道時自動建立專屬語音空間，該空間於閒置無人時自動銷毀。
- **定時推播服務**：每日排程推播 Google 台灣熱門新聞。
- **限免遊戲監控**：自動偵測並推播 Epic Games, Steam 等平台之限時免費遊戲資訊。
- **生活輔助查詢**：提供即時天氣資訊及餐飲推薦服務。

### 🏅 等級與個人檔案系統 (`leveling.py`, `profile.py`)
- 具備防洗頻機制之經驗值獲取系統與升級通知。
- 提供伺服器成員活躍度排行榜。
- 個人檔案卡片整合展示：顯示虛擬資產餘額、當前等級與已解鎖之特殊成就稱號。

### 🛡️ 伺服器管理與日誌 (`admin.py`, `logger.py`, `auto_reply.py`, `bug_report.py`, `error_handler.py`)
- **日誌系統**：完整記錄訊息刪除與編輯、成員進出（包含邀請者追蹤）、語音頻道動態、頻道變更及指令使用狀態。
- **自訂自動回覆**：管理員可針對特定關鍵字設定專屬之觸發回覆內容。
- **全域問題回報系統 (Ticket)**：完美攔截各類指令錯誤並附上「🚨 建立報錯單」按鈕，處理完畢後自動備份對話紀錄並傳送予管理團隊。
- **管理工具**：支援管理員批量清除頻道訊息及一鍵熱重載 (`!hotfix`) 維護功能。

## 🚀 環境需求

- Python 3.8+
- `discord.py`
- `google-genai` (Gemini API)
- `yt-dlp` & `PyNaCl` (用於音樂與語音)
- `FFmpeg` (音樂播放必備環境組件)
- `aiosqlite` / `aiohttp` / `Pillow`

## ⚙️ 安裝與執行

1. **複製原始碼到本地端**
   ```bash
   git clone <你的 GitHub Repo 網址>
   cd <專案資料夾>
   ```

2. **安裝 Python 依賴套件 (Dependencies)**
   ```bash
   pip install -r requirements.txt
   ```

3. **設定環境變數**
   在根目錄下建立一個 `.env` 檔案，並填入以下資訊：
   ```env
   DISCORD_TOKEN=你的_DISCORD_BOT_TOKEN
   GEMINI_API_KEY=你的_GOOGLE_GEMINI_API_KEY
   ```

4. **啟動機器人**
   ```bash
   python main.py
   ```
   *(註：啟動指令請依據實際專案進入點檔案名稱進行調整)*

## 💾 資料庫與資料持久化
本系統採用輕量級 `SQLite` (`bot_database.db`) 作為資料持久化方案，無須額外架設或設定關聯式資料庫伺服器。系統於首次啟動時，將自動初始化並建立所有核心資料表結構。

## 💡 指令總覽
系統完整支援 Discord 斜線指令 (Slash Commands) 與傳統前綴指令。
使用者可於文字頻道內輸入 `/help` 呼叫內建之互動式指令選單，以檢視詳細指令分類與功能說明。
